                           🏺 KHNUM MANIFESTO

Khnum is not built to become the biggest geometry engine.

Khnum is built to become one of the clearest.

Every class should be understandable.
Every algorithm should be correct.
Every public API should feel intentional.

We value:

• Mathematical correctness over clever tricks.
• Immutability over hidden state.
• Readability over unnecessary optimization.
• Explicit APIs over magical behavior.
• Testing as part of design.
• Documentation as part of engineering.

A class is finished only when:

✓ it builds
✓ it is tested
✓ it is documented
✓ it is understandable

We optimize only after measurement.

We duplicate neither mathematics nor responsibilities.

Small, focused classes compose into larger systems.

The engine should be enjoyable to read,
not only enjoyable to use.

If someone discovers Khnum years from now,
they should be able to understand the design
without reading its history.

That is our standard.

                           — The Khnum Project

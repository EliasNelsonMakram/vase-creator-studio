# 🏺 Khnum Engine

> Geometry with Purpose.

Khnum is a modern, renderer-independent computational geometry engine
written in TypeScript.

It emphasizes:

• Mathematical correctness
• Immutable data structures
• Clear, expressive APIs
• Comprehensive testing
• Long-term maintainability

Whether generating meshes procedurally, importing CAD data,
or building algorithms for computational geometry,
Khnum provides a solid mathematical foundation.
